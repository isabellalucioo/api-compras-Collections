Projeto desenvolvida durante a conclusão de curso da Alura - Trabalhando com listas e coleções de dados.

# O que faz:
- Cria um cartão de crédito com limite que você imputa.
- Cria produtos, em que você coloca o nome do produto e o valor e os compra de acordo com esse limite 
- Ao acabar o limite, mostra que não há limite e cancela a compra.
- Ao encerrar, mostra as compras feitas no cartão  + saldo restante.
- *Feature bonus*: Cancela uma compra para recuperar o limite do cartão.

# Tecnologias utilizadas

- Java
- IntelliJ IDEA

# Conceitos praticados:
- Java Collections
- Interface List e seus métodos
- Refatoração e design de classes
 

#  Funcionamento:
- Classe Cartão - Faz operações com saldo e executa as regras de transação.
- Classe Menu - Domina a scanner, lista e mensagens.
- Classe Mensagem - Organiza todas as mensagens(Facilita a alteração)
- Classe Produto - Guarda os atributos dos objetos e executa o compareTo da lista
